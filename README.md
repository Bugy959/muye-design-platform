# 木叶义齿设计平台

连接医院/加工厂与远程设计师的数字化建模协作平台（义齿数字化设计）。

- **三端**：医院端（下单）/ 设计师端（接单设计）/ 管理端（运营审核）
- **技术栈**：React 19 + TypeScript + Vite 7（前端）；Node 24 + Express + SQLite（后端）
- **当前状态**：V2.9（2026-08-23），前端已对接后端 API；OSS 大文件直传代码已就绪，待配置云账号密钥后上线

## 快速开始

```bash
# 前端
cd website && npm install && npm run dev     # :3000
# 后端
cd server && npm install && npm start        # :3001
```

或直接双击根目录 `start.bat`（同时拉起前后端）。
